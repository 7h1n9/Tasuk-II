# API 概览

- `GET /api/v1/challenges`
- `POST /api/v1/instances`
- `GET /api/v1/instances/{instance_id}`
- `POST /api/v1/instances/{instance_id}/reset`
- `DELETE /api/v1/instances/{instance_id}`
- `POST /api/v1/instances/{instance_id}/submit`
- `GET /api/v1/runs`
- `POST /api/v1/runs`
- `POST /api/v1/runs/{run_id}/events`
- `POST /api/v1/runs/{run_id}/tool-calls`
- `POST /api/v1/runs/{run_id}/finish`
- `GET /api/v1/stats`
