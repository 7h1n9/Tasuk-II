## 迁移顺序

1. P0：`core-d01`，补充真实的内部可观察目标和请求证据。

3. 每题必须独立目录、独立 Dockerfile、`public/internal` 元数据、业务首页和 `tests/solve.py`。
4. 迁移完成后删除该题的 `legacy` 标记，并执行元数据身份、公开字段过滤、提示渐进、动态 Flag、重置失效和人工链路测试。
